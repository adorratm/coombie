# Prompt 6 – Performance

Act as a senior game engine performance engineer.

Analyze my survivor-like game for performance bottlenecks.

The game should support:

- 500-1000 simultaneous enemies.
- Hundreds of projectiles.
- Large amounts of particle effects.
- Multiple active weapon systems.
- Continuous enemy spawning.

Analyze:

- CPU usage
- GPU usage
- Memory allocations
- Physics overhead
- Collision detection
- Rendering batches
- Animation overhead
- Object pooling

Identify bottlenecks before modifying code.

Implement optimizations incrementally.

Do not sacrifice gameplay accuracy or visual quality.
