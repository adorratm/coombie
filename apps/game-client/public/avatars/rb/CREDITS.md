# Character models

All `op_*.glb` and `zombie_*.glb` files here are converted from the
**Microsoft Rocketbox Avatar Library** — https://github.com/microsoft/Microsoft-Rocketbox
License: MIT, Copyright (c) Microsoft Corporation.

Conversion: `scripts/rocketbox/build-all.mjs` (simplified mesh, single texture atlas, WebP).
Zombie look (rot, blood, bile, eyes, silhouette) is applied at runtime by `src/zombieLook.ts`.
Source map: `scripts/rocketbox/roster.json`.
