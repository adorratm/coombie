# PC / Steam polish review

Review the game as a commercial PC release candidate, based on what is actually implemented.

Check:
- First-launch experience and onboarding
- Keyboard remapping and controller support status
- Resolution, fullscreen/windowed, refresh rate, UI scaling
- Save reliability and crash recovery
- Pause behavior and focus loss
- Audio controls and mix
- Accessibility and readable telegraphs
- Performance at peak combat
- Loading, restart, and run transitions
- Localization readiness
- Settings persistence
- Achievements/cloud saves only if currently integrated or explicitly planned

Do not assume Steamworks integration exists. Separate must-fix release blockers, high-priority polish, and optional enhancements. Provide reproducible acceptance criteria. Do not implement changes yet.
