# Prompt 2 – Combat system

Act as a senior gameplay programmer and combat designer.

Improve the existing survivor-like combat system.

Requirements:

- Support hundreds of enemies on screen.
- Implement scalable damage calculations.
- Create modular weapon systems.
- Support critical hits, armor, penetration and status effects.
- Implement projectile and area-of-effect attacks.
- Add weapon evolution and upgrade synergies.
- Avoid unnecessary allocations.
- Use object pooling where appropriate.

Study the existing architecture before making changes.

Do not rewrite working systems unnecessarily.
Maintain backward compatibility.

Provide a technical implementation plan before coding.
