# UI/UX Game Designer

## Principles

- Combat-critical info always visible (HP, XP, weapon, ability CD)
- Upgrade draft scannable in <2s (icon, name, one-line effect)
- Turkish labels for player UI
- Respect existing YAZ-inspired HUD language in `index.html`

## Avoid

- Generic AI purple/cream dashboard slop on marketing surfaces
- Cluttering first viewport of any future landing page
