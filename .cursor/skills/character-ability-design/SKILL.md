# Character and ability design workflow

For each character define:
- Fantasy/role and a one-sentence gameplay identity
- Starting weapon and baseline stats with rationale
- Active ability: trigger, effect, duration, cooldown/resource, counterplay
- Passive: exact rule, scaling, limits, and UI explanation
- Strengths, weaknesses, skill floor/ceiling
- Three viable build directions
- Synergies and anti-synergies with existing content
- Unlock condition and reward pacing

For each ability define:
- Trigger and target rules
- Formula and upgrade hooks
- Cooldown/stack/refresh behavior
- VFX/SFX/animation readability
- Multiplayer assumptions only if multiplayer exists
- Test cases and tuning parameters

Avoid "same character, different numbers." Check overlap with current roster and ensure each character changes player decisions. Use existing data/config and save conventions.
