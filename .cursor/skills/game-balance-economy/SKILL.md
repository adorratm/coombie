# Balance and economy workflow

- Inventory all relevant tunables and identify their source of truth.
- Define the target run length, player power curve, expected level cadence, enemy pressure curve, and intended difficulty bands.
- Analyze damage per second, time-to-kill, survivability, XP/minute, upgrade frequency, currency/minute, and reward pacing as appropriate.
- Model best-case, average, and struggling-player scenarios.
- Check for dominant strategies, dead upgrades, runaway scaling, resource hoarding, and grind walls.
- Use data tables, simulations, or telemetry if available; otherwise label estimates and assumptions.
- Make changes in small, reversible tuning increments.
- Preserve save compatibility and economy integrity.
- Provide a before/after balance table and a playtest checklist.
