# Survivor-like UI/UX review

Use `/ui-ux-survivor`.

Review the actual UI framework and current game screens. Evaluate HUD hierarchy, XP/level-up choices, character selection, pause, results, settings, accessibility, keyboard/controller navigation, resolution scaling, and localization readiness.

For each issue provide screenshot/state reference if available, severity, player impact, and a concrete recommendation. Propose a consistent visual language that fits the existing art direction. Do not replace the UI framework. Do not implement until I approve the prioritized design.
