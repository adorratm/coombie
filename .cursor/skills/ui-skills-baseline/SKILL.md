# UI Skills Baseline (from ui-skills.com)

- **Typography & Hierarchy**: Primary status readouts (HP, Ammo, Wave Timer) must have immediate contrast and distinct size hierarchies. Secondary information (sub-stats, passive descriptions) stays subtle.
- **Visual Contrast**: Dark apocalyptic backdrops require clear, accessible contrast on HUD texts and icons without causing eye strain.
- **Component Consistency**: Use standardized padding, border-radius tokens, and responsive scaling suitable for full-screen game interfaces.
- **State Clarity**: Cooldown states, active buffs, and low-health danger states must have distinct visual feedback (e.g. pulse, glow, tint) rather than plain numbers alone.
